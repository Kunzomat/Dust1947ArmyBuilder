📋 DEINE NÄCHSTEN SCHRITTE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─ SCHRITT 1: MySQL starten ─────────────────────────────────────┐
│                                                                 │
│  1. Öffne das XAMPP Control Panel                              │
│  2. Klicke auf "Start" bei MySQL                               │
│  3. Warte ca. 5-10 Sekunden                                     │
│  4. ✅ MySQL sollte GRÜN angezeigt werden                       │
│                                                                 │
│  MySQL erstellt automatisch neue, saubere Log-Dateien!         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ SCHRITT 2: Verbindung testen ─────────────────────────────────┐
│                                                                 │
│  1. Öffne phpMyAdmin im Browser:                               │
│     http://localhost/phpmyadmin                                │
│                                                                 │
│  2. Prüfe, ob deine Datenbanken sichtbar sind                  │
│  3. Teste eine einfache Query                                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ SCHRITT 3: Backup erstellen (WICHTIG!) ──────────────────────┐
│                                                                 │
│  Führe aus:                                                     │
│  .\backup-database.bat                                          │
│                                                                 │
│  Dies erstellt ein vollständiges Sicherungs-Backup             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ SCHRITT 4: Recovery-Modus deaktivieren ──────────────────────┐
│                                                                 │
│  Führe aus:                                                     │
│  .\disable-recovery-mode.bat                                    │
│                                                                 │
│  WARUM? Im Recovery-Modus läuft MySQL mit Einschränkungen.     │
│  Nach Deaktivierung: MySQL normal neu starten!                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─ SCHRITT 5: Deine App testen ─────────────────────────────────┐
│                                                                 │
│  Führe aus:                                                     │
│  .\start-dev.bat                                                │
│                                                                 │
│  Öffne: http://localhost:3000                                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
